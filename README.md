# ARFP: Asymmetric Reversible Face Protection

**Code coming soon.**

ARFP is a restoration-aware framework for key-conditioned, reversible face privacy protection. It integrates Key-Conditioned Manifold Binding, Adversarial Restoration-Aware Training, and Authorized Reversible Restoration with nonce-based tamper indication.

## Paper

- **Title:** Asymmetric Invertible Threat: Learning Reversible Privacy Defense for Face Recognition
- **Authors:** Jiabei Zhang, Ziyuan Yang, Andrew Beng Jin Teoh, Yi Zhang
- **Venue:** NeurIPS 2026
- **OpenReview:** https://openreview.net/forum?id=P0mFHNVW04
